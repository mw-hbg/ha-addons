|---|---|
| [Garmin Connect MCP](garmin_mcp/README.md) | Let AI assistants (Claude, ChatGPT, …) read your Garmin Connect training and health data and plan workouts on your watch. |

## Installation

1. *Settings → Apps (Add-ons) → Store → ⋮ → Repositories*, add
   `https://github.com/mw-hbg/ha-addons` – or click the button above.
2. The add-ons appear in the store. New add-ons in this repository show up
   automatically.

Requires Home Assistant OS or Supervised. Each add-on has its own
documentation (also shown in the add-on's *Documentation* tab).
